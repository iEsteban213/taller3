Cómo obtener tu API Key

Para usar OpenWeatherMap en producción:

  1. Regístrate en openweathermap.org
  2. Ve a tu perfil → API Keys
  3. Copia tu clave gratuita
  4. Pégala en la URL: ?appid=TU_KEY
Esta demo usa wttr.in — API pública sin key necesaria. Ideal para practicar. 🌍
